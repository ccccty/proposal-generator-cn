## 1. 文体铁律（先背这十条，再谈别的）

### 1.1 第 0 条（总则）

**正文是一份「已经想清楚了的方案」，不是「一份正在整理的工作稿」。**

真件作者**自己承担全部不确定性**：数值是他定的，条件是他选的，材料是他已有的。读者（评审专家）从正文里**看不到任何犹豫痕迹**。所有犹豫、待补、待查、待盖章的东西，**全部搬进随附清单**（见 §3），正文对应位置写成**确定句**。

### 1.2 正文禁止出现（逐条核查，出现即不合格）

| # | 禁止项 | 说明 | 凌霄件实测 |
|---|---|---|---|
| 1 | **【待核实】/【待确认】/【TBD】等标记** | 正文出现一个即破坏「已定方案」的可信度 | 0 处 |
| 2 | **来源标注 / 出处标注**（「来源：××」「据××报道」「见××链接」） | 真件不标注来源，作者直接陈述 | 「来源」0 处、「http」0 处、「www.」0 处 |
| 3 | **参考文献 / 脚注 / URL** | 凌霄件全文**无一处 URL、无参考文献表**；研究现状靠**点名学者+机构**承担可信度 | 0 处 |
| 4 | **「公开渠道未见」「未获取」「暂缺」** | 这是元信息，不是正文内容 | 「公开渠道」0 处 |
| 5 | **「本文件为草稿」「供内部讨论」「初稿」等状态声明** | 同上 | 「草稿」0 处 |
| 6 | **合规声明 / 保密声明 / 非密声明** | 这类声明**单独成页**或在专门栏位，**绝不混入正文段落**（凌霄件的诚信承诺单独成章「九、」） | 「合规」0 处 |
| 7 | **形式审查自查表 / 打分自评表 / 打钩清单** | 自检是你自己的动作，不进正文 | 「自查」「形式审查」各 0 处 |
| 8 | **AI 使用说明（作为正文段落时）** | 若制度要求声明，按官方规定的位置与格式放，**不要写成正文里的一段论述** | 0 处 |
| 9 | **写作指令残留**（「此处插入流程图」「（待补图）」「请补充××」） | 图直接编号+题注占位，说明图是什么，而不是说明「这里要放图」 | 无 |
| 10 | **元话语**（「本文档」「本申报书」「如上所述，本文件旨在……」） | 直接进入内容 | 无 |
| 11 | **「可能」「或许」「大概」「预计有待论证」等对冲词堆叠** | 结论用「实现」「定为」「能够」；条件用「在……情况下」 | 正文论述为断言式 |

> 实测方法与结果：对凌霄件全文 44,864 字符做子串计数，「待核实」「来源」「公开渠道」「草稿」「合规」「自查」「形式审查」「http」「www.」「参考文献」「注释」「AI」「版权」**命中数全部为 0**。这是「正文零元信息」这一结论的硬证据。

### 1.3 正文必须出现（做到这五条，文体就对了）

1. **确定的数值，且自带论证。** 每一条指标都是「**数值 → 现有技术基线 → 本项目为何能超过 → 因此定为该值**」，不写「该指标有待与指南核对」。
2. **具体到可核查的专有名词。** 具体型号事件、具体机构、具体学者、具体模型名（如 Dot-Curve、EL2-Net、MS-FPM、Att-Bi-LSTM）、具体章节编号。
3. **物理机理与因果关系。** 说「能达到 X」就同时说清「因为什么机理能达到 X」。凌霄件的每一段指标论证都落到成像机理/干扰机理上。
4. **图，且每图有编号+题注。** 研究内容每个子项末尾**紧跟一张图**；技术路线一节以总图开篇。
5. **闭环收束句。** 研究现状段末必须收束到「现有方法不行→因此需要新算法」；研究内容段末必须收束到「实现……」。

### 1.4 语气与句式基线

- **人称**：正文用**无主语句式**（「本项目研究……」「在此基础上，提出……」），**不用第一人称「我」**。「本人」只出现在科研诚信承诺书（属表单文本，非论述正文）。
- **动词**：研究 / 分析 / 构建 / 建立 / 突破 / 实现 / 揭示 / 挖掘 / 验证 / 估算。**避免**：尝试 / 探索 / 打算 / 计划（「拟」仅可用于栏目名「拟解决的关键科学问题」本身）。
- **收束词**：「实现……」「解决……」「为……提供理论依据与技术支撑」「具有重要的工程应用价值」。
- **程度词必须有依据**：写「高精度」就要在上下文中给出可比较的精度基线（凌霄件写「检测精度能达到90%」作对照）。

### 1.5 一句话检查法

> 把正文交给一个**没见过这份文件的人**读。如果他读出「作者对自己的方案很有把握，且知道为什么」，文体就合格；如果他读出「作者在整理资料、还需要确认很多东西」，就不合格。

### 2.1 项目摘要

- **该节写什么**：一段连续长文（凌霄件摘要**不分段、无小标题**，约 530 字）。结构固定四拍：**① 领域价值与目标 → ② 现状为何做不到（干扰/难点，用「然而……」转折）→ ③ 本项目做了什么（三到四个动作，用分号串联）→ ④ 价值收束**。
- **句式模板**：
  ```
  对……实现……是保障……的有效手段之一。……（正向价值）
  与……相比，……更易于……，同时……包含……信息，通过……，可以……，实现……。
  然而由于……的多样性和……的复杂性，……易受到……干扰，同时存在……，导致……困难，本项目研究……，挖掘分析……，结合……，得到……，实现……；……（第二个动作，用分号）；……（第三个动作），实现……。
  本项目相关工作可为……提供理论依据与技术支撑，具有重要的工程应用价值。
  ```
- **示例**（凌霄件摘要，节选，78 字）：
  > 「然而由于红外图像海上目标特征的多样性和海洋背景的复杂性，红外影像尾迹提取易受到海浪杂波及与舰船相似度高的岛屿等背景干扰，同时存在云雾会淹没目标特征，导致尾迹提取困难」
- **常见错误**：写成「背景-意义-目标-内容-预期成果」的五段式小标题列表（那是开题报告）；写「本项目拟……」；摘要里出现【待核实】；摘要前加「摘要：」（凌霄件表头就是「摘 要」二字，正文直接起笔）。

### 2.2 立项依据（一）基本概念及内涵

- **该节写什么**：**名词逐条定义段**。格式为「术语：定义句。」一行一条，**不编号、不列表格、不引用文献**。顺序是：先定义**研究对象本身**（总概念）→ 再定义**它分解出的子概念** → 再定义**本项目要用的理论工具** → 最后定义**要输出的态势类概念**。
- **凌霄件的定义条目顺序（9 条，实测）**：舰船尾迹（总）→ 开尔文(Kelvin)尾迹 → 湍流尾迹(热尾迹) → 红外图像 → 随机粗糙场理论(Dot-Curve描述体系) → 海面高度场 → 海面温度场 → 意图态势 → 方向态势 → 运动状态态势。
- **句式模板**：
  ```
  <术语>：<现象/原理的产生原因一句>。<形态或表征描述一句>。<在本项目中的含义/约定简称一句>。
  ```
  最后一句常写成「**本项目多用……指代**」「**本项目指代……**」，把术语收敛到项目自己的口径上。
- **示例**（凌霄件，76 字）：「湍流尾迹(热尾迹)：湍流尾迹位于船体的正后方区域，一般表现为有一定宽度的带状区域，光学遥感图像上的含气泡亮尾迹就集中在这片区域。本项目多用热尾迹指代。」
- **常见错误**：写成教科书式综述（带年份、带学者、带引用）；术语只有名称没有定义；定义里塞进「该术语的准确定义有待考据」这类元信息。

### 2.3 立项依据（二）1. 应用需求

- **该节写什么**：三段式。
  1. **需求锚点段**：一个**具体的、可公开核实的真实事件**，把「需求」从抽象变成具体。凌霄件用的是 2023-06-17 某航母编队进入南海、卫星图像上 8 艘军舰尾迹长短差异 → 反推加速接近。**这一段是全节可信度的支点**。
  2. **技术难点段**：用 (1) ……；(2) …… 编号列出**两到三条**具体难点，每条都要写清「干扰源是什么→造成什么后果」。
  3. **本项目回应段**：以「**针对以上问题，本项目研究……**」起笔，把刚才的难点逐条对上自己的动作，用分号串成一句长句。
- **句式模板**：
  ```
  （锚点段）<时间>，<具体事件>。<由公开图像/资料可观察到的具体现象>，表明<蕴含的战术/技术结论>。由于……，与……相比……更易于……，且在……环境下……可持续……时间量级。同时……包含了……信息，通过对……的建模分析可以实现……，有助于实现……。
  （难点段）然而目前国内外……技术难点还未得到有效解决，面临的技术难点和挑战很多，比如：(1)……，会造成……；(2)……，导致……，影响……。
  （回应段）针对以上问题，本项目研究……，挖掘分析……，结合……，得到……，实现……；结合……，实现……，并将……，实现……。
  ```
- **示例**（凌霄件，62 字）：「由于舰船在海面航行时，不可避免的会产生尾迹，与舰船本身相比尾迹更易于检测，且在昼夜环境下红外图像舰船尾迹均可持续数分钟时间量级。」
- **常见错误**：需求写成一堆政策口号（「国家高度重视」）；难点只有一条且笼统（「环境复杂」）；回应段与难点没有一一对应；在难点里写「具体干扰强度有待实验确定」。

### 2.4 立项依据（二）2. 科学意义

- **该节写什么**：**拔高段**。从技术问题跳到**作战效能 / 国防能力 / 军事强国**层面。凌霄件的落点是「精确性、到达范围及连通性」这组三维度，并明确写「是关乎我国建设军事强国的关键一环」。三段结构：
  1. **时代语境+总判断**（信息化作战、联合作战效能、海战场地位）；
  2. **技术制约的后果链**（本技术手段的优势 → 但受什么制约 → 制约了什么 → 成为什么瓶颈）；
  3. **「针对上述问题，通过研究……」的总览段**，把三大方向再拔高一次。
- **句式模板**：
  ```
  随着……的不断发展与深入，……将会极大地提升……效能，……作为……，如何……、能否……，将……进行全方位提升是关乎我国建设……的关键一环。
  ……具备……优势，但同样带来了……等问题，……影响着……的精确性，制约了……在……中的应用前景，制约着……的可靠性，是实现……，提升我国……需要突破的技术瓶颈。
  针对上述问题，通过研究……，构建……，揭示……，建立……，从……层面提高……能力，实现……，对……具有重要意义。
  ```
- **示例**（凌霄件，84 字）：「随着信息化作战理念的不断发展与深入，新概念和新技术的出现及应用将会极大地提升联合作战的效能，海战场作为现代战争的主要作战区域……将海洋军力在精确性、到达范围及连通性等方面进行全方位提升是关乎我国建设军事强国的关键一环。」
- **常见错误**：拔高不足（止步于「具有工程意义」）；拔高过度且与技术内容脱节（直接喊口号）；把科学意义写成应用需求的重复。

### 2.5 立项依据（三）研究现状

- **该节写什么**：按 1./2./3./4. **分主题**写（凌霄件 4 个主题：红外图像尾迹特征分析 / 红外图像尾迹提取方法 / 海面尾迹红外仿真模型建立 / 舰船态势推理模型）。每个主题的写法是固定的三拍：
  1. **技术陈述**：这个方法类别的原理与形态；
  2. **点名综述**：**点名学者与机构**，一人一句，说他做了什么、他的方法适用/不适用于什么；
  3. **收束判断**：以「**由上述研究可知虽……但……仍没有很好的解决方法，……因此需要寻找新的算法**」结束。
- **点名与机构（凌霄件实例，此处引用仅为说明「点名」这一文体动作）**：海军工程大学的顾建农教授、种劲松等人、牛蕾等人、Ai 等人、Lord Kelvin（19 世纪 80 年代）、Fournier 等人；机构层面的「海军工程大学」「海军潜艇学院」「国防科技大学」；态势推理方向点名了 JDL 初级模型（1984，美国国防部数据融合联合指挥实验室）、《2020 年联合构想》、何树权等人（2003）、赵宗贵等人（2010）、胡晓峰等人（2017）。**全文无一处 URL、无脚注、无参考文献表（实测 0 处）。**
- **句式模板**：
  ```
  （技术陈述）近年来很多学者对……研究大都是基于……进行的，并基于……建立了……模型。……表明：……越明显；同时，随着……的增大，……逐渐增大。
  （点名综述）<机构><姓名/课题组>等人提出<方法名>，<一句话原理>，但是<适用边界>。……<同句式重复 2–4 次>。
  （收束）由上述研究可知虽然……不断研究改进，一定程度上提高了……精度，但受限于……，对于……问题依旧没有很好的解决方法，存在……等问题，无法满足……需求，因此需要寻找新的算法……
  ```
- **示例**（凌霄件研究现状收束句，65 字）：「由上述研究可知虽然尾迹检测算法不断研究改进，一定程度上提高了尾迹检测精度，但受限于红外遥感图像中尾迹特征的多样性和背景的复杂性，对于红外图像尾迹特征不明显问题依旧没有很好的解决方法」
- **常见错误**：**加 URL、加脚注、加参考文献表**（凌霄件 0 处）；写成「国外研究现状/国内研究现状」两段式而**不分技术主题**；只讲趋势不点名不点机构（不可信）；有综述**没有收束判断句**；在收束句里写「该方向研究进展有待进一步调研」。

### 2.6 研究目标

- **该节写什么**：**一段**（凌霄件为单段，约 290 字），不分条。把摘要扩写一档，末句落到「实现……的推理」。
- **句式模板**：
  ```
  对……实现……是保障……的有效手段之一。与……相比……更易检测，……环境下……可持续……量级，且包含了……信息。基于……的方法容易受到……的影响，本项目针对……进行了详细的分析，结合……，获取了……特征，研究基于……的方法。同时研究……，建立完整的……数据库。构建……模型，通过对……，估算……，实现……的推理。
  ```
- **示例**（凌霄件研究目标末句，72 字）：「构建多场景舰船态势推理模型，通过对提取的舰船尾迹与尾迹数据库进行匹配，估算目标航速航向，实现舰船意图态势、方向态势以及运动状态态势的推理。」
- **常见错误**：写成「1. 目标一 2. 目标二」的条目列表（凌霄件不分条）；目标里出现「力争」「争取达到」；目标与指标脱节（目标写了方向，指标却考别的东西）。

### 2.7 拟解决的关键科学问题

- **该节写什么**：**3 条编号**（凌霄件正好 3 条），每条**一句话**，句式高度固定。三条要有层次：第 1 条是**表征/建模层**，第 2 条是**算法/提取层**，第 3 条是**体系/验证层**。
- **句式模板**（由凌霄件三条归纳的共用骨架）：
  ```
  <序号>.针对<问题>问题，运用<方法/理论>，构建/突破<新体系>，<动词>传统<旧范式>，<深入/有效><做什么>，解决<什么障碍>。
  ```
  变体：「基于<现象>，运用<方法>，结合<模型>，解决<问题>，建立<算法>，以实现<目标>」。
- **示例**（凌霄件第 1 条，112 字，已按 ≤120 字上限节选）：「针对红外舰船尾迹影像存在场景复杂性问题，运用随机粗糙面理论，构建空间曲面描述体系，突破传统二维特征描述方法，深入挖掘目标与背景的空间纹理信息，有效完成场景特征区分模型构建，解决云雾、陆地、岛屿存在干扰尾迹提取的线性机理影响。」
- **常见错误**：条数写成 4–6 条且互不区分层级；写成「研究内容」的复述（科学问题要指「卡点」，不是「任务」）；缺少「突破/解决/建立/实现」这类动作收束。

### 2.8 研究内容（**全文主体，占 60–70% 篇幅**）

凌霄件的研究内容分两大部分，比例与结构都必须照此。

#### （1）1. 主要研究内容 = 1.1 / 1.2 / 1.3 / 1.4，每个子项**一段 + 紧跟一张图**

- **每段写法**：「针对<问题>，本项目<动作>，<动作>，……，实现<结果>。」**只写一段**（凌霄件每段约 120–200 字），不分子条目。
- **图**：每段末尾紧跟该子项的**技术流程图**，编号 **图4-1 ~ 图4-4**，题注为该子项名 + 「技术流程图」。
- **示例**（凌霄件 1.2 段，截取 94 字）：「针对红外图像整体对比度较低的问题，首先对图像进行多方向Gabor滤波、多尺度差分金字塔处理，提高图像对比度，同时实现图像增强以及图像去噪等效果。提出了基于随机粗糙面理论(Dot-Curve)体系的舰船尾迹搜索算法」
- **图题注写法（凌霄件实测原文）**：
  ```
  图4-1 海面场景红外图像特征分析技术流程图
  图4-2 多尺度多方向的尾迹纹理特征提取
  图4-3 基于温度和几何模型的红外图像尾迹建模仿真
  图4-4 多场景舰船态势估计与推理
  ```
  **图号用了章号「4」作前缀**——研究内容属于第四章，故为「图4-x」；图与题注之间**不留「图略」「见附件」之类说明**。

#### （2）2. 主要技术路线 = **总图开篇 + 分层展开**

- 结构：先给 **「图4-5 总体技术路线图」**，然后用 2.1 / 2.1.1 / 2.1.2 多层编号逐块展开，每块内含定义、推导、公式（公式位置留空行占位）、实验结果图。
- 这一部分是**全文最长的一段**（凌霄件的 2.x 从图4-5 一路排到图4-57）。
- **示例**（凌霄件 2.1.1 的 Dot-Curve 定义段起笔，89 字）：「用于场景建模的Dot-Curve描述体系，也称随机粗糙面理论，是指图像用曲面来表征的理论。首先，将图像看成空间曲面，令图像的行方向为ｘ轴，列方向为ｙ轴，则图像的灰度值能构成一个三维曲面」
- **常见错误**：
  - 研究内容**只有一段总述**，没有逐子项段落（等于把主体砍掉）；
  - **图只用文字说「此处应有图」**而不给编号题注；
  - 把研究内容写成**任务分解表**（用表格列「任务/负责人/时间」）；
  - 研究内容与关键科学问题**不对应**。

### 2.9 研究周期及阶段划分

### 2.10 考核指标（**文体最「硬」的一节，必须照抄其论证结构**）

- **该节写什么**：**「一句指标 + 一整段论证」**，指标逐条编号 1) 2) 3)。论证段是**五拍**：
  1. **给出数值**（写在编号句里，句末加句号）；
  2. **说明现有技术水平基线**（给一个数！凌霄件分别给了 90% / 90%以上 / 95%）；
  3. **说清现有方法为何不够**（干扰源、失效条件）；
  4. **本项目方法为何能超过**（落到机理与特征上）；
  5. **收束**：「**因此……定为 X，……定为小于 Y。**」
- **句式模板**：
  ```
  <n>)实现<指标名>大于<数值>，<指标名>小于<数值>。
  <场景>下的<任务>，成像系统面对<条件>，易受<环境因素>的影响，导致<后果>；同时<图像/数据>中存在的<干扰1>、<干扰2>、<干扰3>等也会影响<任务>的<准确度>。利用传统方法<做什么>，其<指标>能达到<基线数值>，但面对<相似特性干扰物>仍会出现<错误>，同时由于<客观条件>，使得<困难描述>，这也使得<困难描述2>存在着一定的困难。因此,对<什么>进行特性分析及对比就显得尤为重要，本项目基于<差异/机理>，分析其背后蕴含的物理规律，以<特征>作为特征进行筛选，能够实现<结果>……因此<指标>定为<数值>，<指标>定为小于<数值>。
  ```
- **示例**（凌霄件指标 1 的论证段，节选 96 字）：「利用传统方法进行尾迹提取，其检测精度能达到90%，但面对与尾迹表现出相似特性的干扰物仍会出现误检，同时由于广阔的海洋面积，使得区域与区域之间海洋背景所表现的特征有一定的差异，这也使得将舰船尾迹从复杂的海洋背景中搜索出来存在着一定的困难。」
- 凌霄件的两条指标句（实测原文，各一句）：
  - 1) 实现目标检出概率大于96%，虚警率小于1E-5。
  - 2) 训练后模拟多场景船舶运动状态态势识别准确率大于98%。
- **常见错误（最致命的是第 1、2 条）**：
  1. **指标只写数值不写论证**（= 占位符，评委无法判断可信度）；
  2. 论证里**没有基线数值**（不说「传统方法能到多少」，就无法说明「为什么要 96%」）；
  3. 只写「显著提升」「国内领先」而无单位无数值；
  4. 在指标旁标注「该值有待与指南核对」——**这属于元信息，必须剥离到随附清单**（见 §3）。

### 2.12 研究成果（预期成果）

- **该节写什么**：分三个层级，每层用 1.1 / 1.2 / 1.3 + (1)(2)(3) 编号。
  1. **技术研究报告**（几项，逐项列名称）；
  2. **论文及发明专利**（数量，凌霄件写「申请发明专利1-2项；发表高质量论文1-2篇」）；
  3. **系统/样机**（**逐条列出该系统具备的 4–5 项能力**，每条也是「能实现……」的断言句）。
- **示例**（凌霄件系统能力条目，节选 2 条）：「(2)构建一个包含不同海况、不同航向、不同航速的舰船尾迹红外图像仿真数据库，能囊括常规情况下大部分舰船尾迹图像。(3)构建尾迹数据库与舰船尾迹特征匹配网络，能实现准确高效的舰船航速航向估算。」
- **常见错误**：把论文/专利数量当主要成果（军口体系公开发表常受保密审查约束，凌霄件把论文列在第 1.2 层而非主体）；成果形式与指南条目要求不一致。

### 2.13 先进性及应用前景分析

- **该节写什么**：**编号条目（针对技术点的先进性）+ 一段总述（应用前景）**。
  - 先进性条目以 1. 2. 开头，句式是「**针对……问题，创新性地建立了/提出了……，……，能有效……**」。**每条必须点明「新增量」**（新建了什么体系、提出了什么方法）。
  - 应用前景段以「**本项目立足……发展方向，以……为红外场景，瞄准……作战要求，立足攻克……等关键技术**」起笔，中段用「可应用于……，实现……」列出应用场景（凌霄件列了「实时海面作战场景」「干扰下的舰船检测」「精准制导和动态海面监测」），末段落到「**对战前早期征候辨识、战中作战方案调整、战后态势发展预测等指挥决策提供辅助支持**」。
- **示例**（凌霄件先进性条目 1，截取 107 字）：「针对红外舰船图像具有的背景复杂性问题，创新性地建立了Dot-Curve检测体系，以二维曲率滤波为基础进行初步的舰船检测和尾迹特征提取，构建场景特征模型，从中选取与背景干扰项差异较大的包含尾迹灰度方差、尾迹两侧灰度斜率正负性等特征」
- **常见错误**：先进性写「首次提出」却无依据（改用「在……范围内未见公开报道」或直接陈述新增量）；应用前景只有口号没有场景；先进性与关键科学问题不呼应。

### 2.14 研究团队、研究基础及保障条件

四小节，写法差异明显。

#### （1）单位简要情况（1 段，约 180 字）
- 句式：「**课题依托单位<全称>是国家……重点建设大学，依托学科……是……重点学科。依托实验室是……重点实验室，可为本项目提供必备的试验条件；……在……方面已经达到国内领先水平，完全具备本项研究所需要的软硬件环境。**」
- 要点：**单位—学科—实验室—能力**四级递进，**不写「有待核实」**。

#### （2）负责人情况（4 个子块）
- 结构固定：**1.个人简介 / 2.受教育经历 / 3.研究工作经历 / 4.代表性成果**。
- 个人简介是**一段密集事实**：学历、职称、导师身份、毕业年份+专业、博后经历、研究方向、**论文数量与分区**（凌霄件：「共发表SCI论文20余篇，其中第一/通讯作者论文6篇，包括3篇一区，2篇二区」）、获奖（具名到奖项与年份）、任职经历。
- 受教育/工作经历用「起止年月 单位，专业，学位/职务」的定长行。
- 代表性成果用「[n] 作者. 题目. 期刊. 年份.」+ **紧随一段「这项成果对本项目的意义」**——凌霄件每篇代表作后面都补一句「**可为……提供技术支持**」「**在……领域具有广泛的应用前景**」，把个人成果**强行拉回与项目的相关性**上。
- **示例**（凌霄件代表作后的相关性句，节选 78 字）：「本方法不依赖或很少依赖于地面数据的先验姿态信息，并且已成功应用于具有显著尺度差异(分辨率相差100倍)的大场景数据集上，可为战场多源信息/数据融合和高精度定位提供有力技术支持。」

#### （3）项目组成员情况
- **纯表格**：序号 / 姓名 / 性别 / 身份证号码 / 职称 / 分工 等。**正文无论述**。
- **本文件不摘录该表内容**（含大量个人信息）。

#### （4）项目研究基础及与有关计划关系
- 结构：**1.研究基础与保障条件**（2–3 段，写单位与实验室的长期积累、合作关系、获奖清单）+ **2.正在承担的基础加强计划项目情况**（**逐项列出在研项目，每项 1 段 + 一张图**，段末必须补一句「**……为本项目研究提供了方法参考 / 奠定了技术理论基础 / 提供了试验条件支撑**」）+ **3.与有关计划关系**（**不适用就直接写「无」**）。
- **示例**（凌霄件在研项目相关性句，节选 58 字）：「『红外监视研究』主要研究红外图像中小目标特性及其检测方法，在研项目解决的红外小目标特性弱、难检测的难题为本项目研究奠定了良好的技术理论基础。」
- **常见错误**：把在研项目写成清单而不写与本项目的关联；「与有关计划关系」留空（应写「无」）；研究基础堆论文数量而不筛相关性。

### 2.15 经费概算（正文只放表）

- **该节写什么**：**正文里只有概算表**，表格三列：科目名称 | 申请经费 | 备注，单位「万元」。
- **凌霄件的完整科目树（实测）**：
  ```
  总经费  100
    （一）直接费用  83.8
        1. 设备费  24        备注：高性能处理器
          1.1 设备购置费  24
          1.2 设备试制费   0
          1.3 其他         0
        2. 材料费  4
        3. 外部协作费  0
        4. 燃料动力费  0
        5. 会议/差旅/国际合作与交流费  9
        6. 出版/文献/信息传播/知识产权事务费  6
        7. 劳务费  36.8
        8. 专家咨询费  4
        9. 其他支出  0
    （二）间接费用  16.2
        10. 管理费/科研绩效支出  16.2
  节点经费预算：协议签订 40 | 项目中期 40 | 项目验收 20
  本项目申请经费100万元，另外自筹经费0万元。
  ```
- **文科**：**表下不加废话**。整个第七章正文只有表格 + 一句「本项目申请经费 X 万元，另外自筹经费 Y 万元。」
- **明细去哪了**：进**附件1《项目经费概算说明》**，那里才是文字场所，写法是「**<科目名>（<金额>万元）** + 一句『总计 X 万元（申请 X 万元，自筹 0 万元）』 + 需要时给明细表或算式」。
- **示例**（凌霄件附件1材料费，算式型）：「试验专用移动硬盘：数据集制作、算法设计及原理验证、试验过程中数据存储，1600元/个×10个=1.6万元；加速内存条：2000元/组×12组=2.4万元；总计4万元。」
- **常见错误**：正文经费章里写大段测算依据（应放附件）；科目口径套错（装发部 10 项 vs 「直接费用 9 项+间接费用」，科目口径的判定见技能文件 SKILL.md §7 第 4 步）；漏掉「申请/自筹」拆分句。

### 2.16 科研诚信承诺书

- **该节写什么**：**固定 7 条**，照抄制度文本，**不改写、不增删**。凌霄件 7 条为：
  1. 严格遵守国家和军队有关科研诚信规章制度……
  2. 不从事任何可能影响立项评议公正性的活动……
  3. **所申报项目研究内容没有通过其它计划渠道立项支持。**
  4. 科研过程真实。……
  5. 学术行为规范。……
  6. 提报材料准确。……
  7. 研究成果可信。……

  **注意第 3 条**：这就是「**重复申报**」承诺所在（SKILL §7 第 14 条形式审查雷区在正文中的落点）。
- 章节末尾固定为「**本人确认已仔细阅读此承诺书的内容，并将上述要求传达至项目组全体成员。**」+ 签字栏 + 日期栏。
- **示例**（凌霄件第 7 条）：「七、研究成果可信。不虚构、拼凑、包装科研成果，不夸大技术水平、应用效果和潜在效益，不隐瞒技术局限与风险，不提供虚假应用证明。」
- **常见错误**：自行改写承诺条款（法律文本不可改写）；漏掉重复申报承诺；把承诺书写成正文风格。

## 3. 元信息剥离规则（上一版项目书最大的文体事故就出在这里）

### 3.1 原则

> **正文承担「确定」，随附清单承担「不确定」。二者物理分离，绝不混排。**

真件作者的全部不确定性都存在于**他自己的脑子里和笔记本里**；交给评审的文本只呈现**已经拍定的结果**。AI 辅助写作时，不确定性来自「缺少用户输入」，但这**不能**变成正文里的标记。

### 3.2 逐类剥离对照表

| 不确定性类型 | ❌ 禁止写在正文里的形式 | ✅ 正文写成什么 | ✅ 写到哪里 |
|---|---|---|---|
| **数值待定**（指标值、经费金额、周期） | 「检出率大于【待核实】，以指南为准」 | 直接给出一个**自洽的数值**，并按 §2.10 五拍法自圆其说：「因此目标检出率定为96%，虚警率定为小于1E-5。」 | 随附清单：「指标1 现值96% — 依据：同类真实申报件实测值；须与指南条目 X 的指标上限核对」 |
| **条件待定**（测试环境、海况等级、样本规模） | 「测试条件待定」 | 写具体条件：「在 3–4 级海况、不同航速航向条件下」 | 随附清单：「海况等级取值须与用户确认」 |
| **材料待补**（合作协议、非密声明、资质证书） | 正文插「（此处待补盖章件）」 | 正文**完全不提**，材料作为独立附件/页面 | 随附清单：「待办：联合申报协议盖章页 ×N」 |
| **事实未取证**（某标准号、某学者观点、某机构数据） | 「该数据来源不明，待查」 | **要么取证后直接写，要么整句删掉不写**——不写没有把握的事实，比写一个带问号的事实强 | 随附清单：「已删：关于××标准的表述，未核到标准号」 |
| **来源标注**（「来源：××」「据公开报道」） | 任何形式的来源标注 | 直接陈述事实，来源不进正文（凌霄件 0 处 URL） | 随附清单：「事实出处对照表：第3章某段 ← 凌霄件 L134」 |
| **合规/程序状态**（是否盲评版、是否走涉密渠道、AI 使用声明） | 正文里一段「合规声明」 | 程序性声明按制度**单独成页/单独栏位**；AI 使用标识按官方规定位置与格式放 | 随附清单：「本版为盲评版，已去身份化，逐项核对见附件」 |
| **自检结论**（哪些通过、哪些存疑） | 正文附「形式审查自查表」 | 自检**根本不进文本**，它是你交付物里的独立文件 | 独立文件：「自检报告（不并入正文）」 |
| **写作状态**（「本文件为草稿」「初稿供讨论」） | 正文首行或页脚 | 不写。交付说明里书面提示即可 | 交付说明 |

### 3.3 随附清单的标准格式（**与正文同批交付，但绝不并入正文**）

```
【随附清单 · 不并入正文】
一、需用户确认的数值（正文中已按现值写死）
  1. 目标检出概率：正文写 96% —— 须核对指南条目指标上限；若指南要求 ≥98%，
     正文改 98% 并重写该段论证的基线数值。
  2. 项目周期：正文写 2 年 —— 须与申报通知的周期上限核对。
  3. 总经费：正文写 100 万元 —— 须与指南经费限额核对；注意直接/间接比例。
二、已删去的内容（因无法取证）
  1. 原拟引用「××标准（GJB ××××）」，未核到标准号与现行版本，已整句删除。
三、待补的附件材料
  1. 联合申报协议（各单位签章页）
  2. 《非密声明》（加盖公章）
四、事实出处对照（供复核，不进正文）
  第2.3节「某航母编队事件」 ← 凌霄件 L134；其余为编写事实。
五、程序性事项
  1. 本版是否按盲评版去身份化：是/否
  2. AI 使用声明与标识：已按制度放置于〈位置〉
```

### 3.4 剥离的判定口诀

> **一句话里出现「待」「暂」「可能不确定」「不适用但……」，就把它拆成两句：一句写成确定的，进正文；一句写成待办的，进清单。**

## 4. 格式与排版规范

### 4.1 章节编号体系（凌霄件实测）

```
一级：  一、 二、 三、 ……（汉字数字 + 顿号）          例：三、立项依据

四级：  1.1  1.2  1.3 ……                              例：1.1海面场景红外图像特征分析
五级：  2.1.1  2.1.2  2.1.3 ……                        例：2.1.1用于场景建模的Dot-Curve描述体系
```
- **次级序号可复用汉字数字**：技术路线内部的小节标题用了「一、云干扰特性分析」「二、海面干扰特性分析」（凌霄件 L202/L216/L227）——说明**正文内部允许用汉字序号独立编号**，不必层层套阿拉伯数字。
- **无内容即写「无」**：凌霄件「3.与有关计划关系」下正文就是「无」（L736）。
- 目录自动生成（TOC 域），一级到二级入目录。

### 4.2 图表编号与题注写法

- **编号规则**：图<章号>-<章内序号>。凌霄件研究内容属第四章，故为 图4-1 … 图4-57（实测最大 **图4-57**，即本章 57 张图）；第六章研究基础为 图6-1 … 图6-4。
- **题注格式**：「图4-1<空格>题注文字」，题注在**图下方**。
- **题注文字要求**：名词性短语，**说清「这是什么图」**，不写「示意图如下」。
  ```
  图4-5 总体技术路线图
  图4-6 曲面Dot与Curve示意图
  图4-7 基于Dot-Curve的目标和背景特征参数定义
  图4-8 各类积云背景及其Dot与Curve部分提取图
  图4-9 积云背景1主轴及副轴曲线图
  ```
- **表格编号**：**独立序列**，用「表1」「表2」（凌霄件实测只有「表1设备费用明细表」「表2 劳务费」，位于附件，**不带章号前缀**）。
- **表格题注在表上方**（「表1设备费用明细表」出现在表格首行之前）。
- **正文引图**：用「如下图4-8所示」「其示意图如下图4-6所示」——**必须回指编号**。

1. **辅源 PDF 文本层已损坏。** 申报书最新版.txt 由 PDF 抽取而来，该 PDF 使用子集字体且**缺 ToUnicode 映射**，导致大量汉字被系统性抽错。**可复现的抽错实例**：

3. **行距倍数不可辨识。** 辅源原文句式为「正文（包括标题）行距为 __ 倍」，PDF 中该数字位为空。**本文件不猜测该数值。** 需要该数值时，请以本单位**当年度转发的模板原件**为准。
4. **凌霄件的局限**：
   - 它是**「基础加强计划」体系的**一份件，**不能代表所有军工计划**（173 技术领域基金、装备预研共用技术、快速支持、国防科工局的模板结构各不相同）。
