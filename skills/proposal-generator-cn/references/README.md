## 关于编号 07、08

本包**没有** `07` 与 `08` 两个文件，这是既成事实，不是缺页：

- `07`：历史上未曾产出（素材整理阶段并入 04 与 10 的内容）。
- `08`：`08-模板原件索引.md` 属于原始素材库的索引文件，未随包分发（它只记录原件字节数与抽取方法，不承载写作规则）。

需要核对模板原件时，**向用户索取原件路径**（不得假设固定盘符）；本包已保留全部可核验结论。

## 使用顺序（最短路径）

1. `00`（5 分钟）→ 2. `01` 里定位计划 → 3. `02` 或 `03` 搭骨架 → 4. `09` 校准文风 → 5. 写作中查 `04` → 6. 写公式查 `10` → 7. 自检查 `05` + `tools/check_proposal.py`。
